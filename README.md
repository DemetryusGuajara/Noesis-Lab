## 🧭 What is Noesis Lab?

**Noesis Lab** is an interactive phenomenological laboratory for Android. It transforms subjective feelings, dilemmas, and abstract thoughts into a **living topological field of spatial forces**, combining philosophy of mind, enactive neuroscience, ambient generative acoustics, and dialectical synthesis.

Rather than treating human emotion as static labels or problems to "fix", Noesis Lab invites the user to physically arrange internal concepts as celestial spheres across a 2D tactile canvas. The spatial configuration—proximity, distance, mass, and tension—reveals the hidden architecture of the present moment.

```
       [ Fear ] (periphery / tension)
          \
           \  (polarity / protective distance)
            \
   [ Courage ] <---- affinity ----> [ Wish ]
        (center / anchor)
```

## 💡 Key Pillars & Capabilities

1. **Spatial Field & Topological Geometry (Tab 1):**
   - Physics-driven 2D canvas with inertia, harmonic attraction, and collision dynamics.
   - Adjust hue (importance/gravity) and heaviness (viscosity/somatic weight).
   - Real-time biofeedback parameters: internal rhythm (arousal), affective openness (valence), and focus depth.

2. **Architectural Map & Relational Graph (Tab 2):**
   - Structural visualizer mapping proximity pairs (alliances/affinities) and polarity vectors (boundaries/tensions).
   - Comprehensive philosophical knowledge base exploring thinkers from Baruch Spinoza to Francisco Varela.

3. **Autonomous Phenomenological Oracle (Tab 3):**
   - **Zero Mandatory External Keys:** Operates independently out-of-the-box in ~80 MB with an on-device dialectical synthesis engine combined with live MediaWiki and Crossref encyclopedic grounding.
   - **Bring Your Own Key (BYOK):** Full native compatibility with OpenAI, Groq, Ollama, OpenRouter, and any OpenAI-compatible API endpoint with custom model selection and live latency verification.
   - **Independent Sessions:** Each session represents a singular, unpolluted inquiry reflecting exclusively the active topology.

4. **Deep Generative Audio Engine & Persistent Media Player:**
   - Real-time generative sound engine combining harmonic root drones, Pythagorean fifths, and soothing ambient waves.
   - Fully compliant Android `MediaSession` integration with a persistent Quick Settings and Lock Screen media player tile.

## 🛠️ Architecture & Tech Stack

- **UI:** 100% Declarative Jetpack Compose with Material Design 3.
- **Architecture:** Clean MVVM with Kotlin Coroutines and `StateFlow`.
- **Database:** Local offline persistence using Android Room (`SQLite`).
- **Audio:** Native low-latency `AudioTrack` PCM procedural synthesis + Android 11+ `MediaSession` Foreground Service.
- **Internationalization (i18n):** Native multilingual support (Portuguese, English, Spanish, French).
