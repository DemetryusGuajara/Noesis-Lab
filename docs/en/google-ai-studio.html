Google AI Studio (Gemini)

Endpoint locked in the app:
https://generativelanguage.googleapis.com/v1beta/openai

1. Create your key

  1. Go to aistudio.google.com/apikey and sign in with Google.
  2. Click Create API key. For basic use no Cloud project is required.
  3. Copy the key (starts with AIza…). Keep it private like a password.

Free tier: Gemini offers a generous no-card free tier with per-minute/day limits. Verify current limits at the official pricing page.

2. Use it in Noesis Lab

  1. Open Noesis Lab → Settings → Google AI Studio (already listed).
  2. Tap + Add key, paste the key, tap Save, Test & Filter Models.
  3. Pick a model chip (★ = active). On rate limit, add a second key and switch its radio.
