OpenRouter

Endpoint locked in the app:
https://openrouter.ai/api/v1

1. Create your key

  1. Go to openrouter.ai/keys and sign in.
  2. Click Create API Key, give it a name and copy the value (starts with sk-or-v1-…).

Free tier: many models have free variants (their IDs end in :free, e.g. on the models page). Free models carry rate limits; adding credits raises them. Check the docs before heavy use.

2. Use it in Noesis Lab

  1. Settings → OpenRouter → + Add key → paste → Save, Test & Filter Models.
  2. The app lists only models that answered the live ping. Pick one (★ = active).
