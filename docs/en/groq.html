Groq

Endpoint locked in the app:
https://api.groq.com/openai/v1

1. Create your key

  1. Go to console.groq.com/keys and sign in.
  2. Click Create API Key, optionally set a display name, and copy the value (starts with gsk_…).

Free tier: Groq offers free access with per-minute/per-day token limits and no card required. Check official pricing and the model list.

2. Use it in Noesis Lab

  1. Settings → Groq → + Add key → paste → Save, Test & Filter Models.
  2. Pick a responding model chip (★ = active).
