Cerebras

Endpoint locked in the app:
https://api.cerebras.ai/v1

1. Create your key

  1. Go to cloud.cerebras.ai and sign in.
  2. Open the API Keys section, click Create API key and copy the value (starts with csk-…).

Free tier: Cerebras is known for very fast inference with a generous free tier subject to daily/request limits. Confirm current limits at cerebras.ai and their docs.

2. Use it in Noesis Lab

  1. Settings → Cerebras → + Add key → paste → Save, Test & Filter Models.
  2. Pick a responding model chip (★ = active).
