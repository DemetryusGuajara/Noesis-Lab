Cloudflare Workers AI

Endpoint template locked in the app:
https://api.cloudflare.com/client/v4/accounts/{account_id}/ai/v1

This provider is special: each key slot needs two fields — the Account ID and the API token. Never edit the endpoint; just fill the Account ID box and the app builds the full URL for you (it updates live when you switch slots).

1. Find your Account ID

  1. Go to dash.cloudflare.com and sign in.
  2. Your Account ID is shown on the right sidebar of any domain overview page (32 hex characters). Copy it.

2. Create your API token

  1. Click your profile icon (top right) → My Profile → API Tokens → Create Token.
  2. Use the Workers AI template (it pre-selects the right permissions) or a custom token with Workers AI access, then copy the token value.

Free tier: Workers AI includes a free daily allowance of requests/neurons. Confirm current limits at the official pricing page.

3. Use it in Noesis Lab

  1. Settings → Cloudflare Workers AI → + Add key.
  2. Fill Account ID (watch the URL preview update) and paste the token, then tap Save, Test & Filter Models.
  3. Pick a responding model chip (★ = active).
