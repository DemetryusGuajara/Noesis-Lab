Nvidia NIM

Endpoint locked in the app:
https://integrate.api.nvidia.com/v1

1. Create your key

  1. Go to build.nvidia.com and sign in with an NVIDIA account.
  2. Pick any chat model, open its page and click Get API Key (or open the API keys section directly) and copy the value (starts with nvapi-…).

Free tier: NVIDIA grants free starting credits for NIM endpoints; heavier use is billed. Confirm at build.nvidia.com and the NIM docs.

2. Use it in Noesis Lab

  1. Settings → Nvidia NIM → + Add key → paste → Save, Test & Filter Models.
  2. Pick a responding model chip (★ = active).
