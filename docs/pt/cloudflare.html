Cloudflare Workers AI

Template de endpoint travado no app:
https://api.cloudflare.com/client/v4/accounts/{account_id}/ai/v1

Este provedor é especial: cada slot de chave precisa de dois campos — o Account ID e o token da API. Nunca edite o endpoint; preencha só a caixa do Account ID e o app monta a URL completa sozinho (atualiza ao trocar de slot).

1. Encontre seu Account ID

  1. Acesse dash.cloudflare.com e entre na sua conta.
  2. O Account ID aparece na barra lateral direita da página de qualquer domínio (32 caracteres hexadecimais). Copie.

2. Crie seu token de API

  1. Clique no ícone do seu perfil (canto superior direito) → My Profile → API Tokens → Create Token.
  2. Use o template Workers AI (já vem com as permissões certas) ou um token custom com acesso ao Workers AI, e copie o valor.

Free tier: o Workers AI inclui cota diária gratuita de requisições/neurônios. Confirme os limites atuais na página oficial de preços.

3. Usando no Noesis Lab

  1. Ajustes → Cloudflare Workers AI → + Adicionar chave.
  2. Preencha o Account ID (veja o preview da URL atualizar) e cole o token, depois toque em Salvar, Testar & Filtrar Modelos.
  3. Escolha um modelo que respondeu (★ = em uso).
