Cerebras

Endpoint travado no app:
https://api.cerebras.ai/v1

1. Crie sua chave

  1. Acesse cloud.cerebras.ai e entre na sua conta.
  2. Abra a seção API Keys, clique em Create API key e copie o valor (começa com csk-…).

Free tier: a Cerebras é conhecida pela inferência rapidíssima com free tier generoso, sujeito a limites diários/por requisição. Confirme os limites atuais em cerebras.ai e na documentação.

2. Usando no Noesis Lab

  1. Ajustes → Cerebras → + Adicionar chave → cole → Salvar, Testar & Filtrar Modelos.
  2. Escolha um modelo que respondeu (★ = em uso).
