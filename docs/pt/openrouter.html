OpenRouter

Endpoint travado no app:
https://openrouter.ai/api/v1

1. Crie sua chave

  1. Acesse openrouter.ai/keys e entre na sua conta.
  2. Clique em Create API Key, dê um nome e copie o valor (começa com sk-or-v1-…).

Free tier: vários modelos têm variantes grátis (o ID termina em :free, veja a página de modelos). Modelos grátis têm rate limit; colocar créditos aumenta os limites. Confira a doc antes de uso intenso.

2. Usando no Noesis Lab

  1. Ajustes → OpenRouter → + Adicionar chave → cole → Salvar, Testar & Filtrar Modelos.
  2. O app lista só os modelos que responderam ao ping ao vivo. Escolha um (★ = em uso).
